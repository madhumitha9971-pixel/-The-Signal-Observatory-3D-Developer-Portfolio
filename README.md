The Signal Observatory: 3D Developer Portfolio

​An immersive, dark-themed interactive portfolio designed as a deep-space radio observatory.
 Visitors explore engineering projects by detecting and decoding signals from distant stars, combining WebGL 3D visualizations with readable technical case studies, a custom CLI terminal, and a mission log.

​Key Features:

​3D Deep-Space Observatory: Built using Three.js and WebGL, featuring a rotating radio telescope mesh, dynamic star particle fields, and real-time mouse coordinate telemetry (Azimuth & Altitude).

​Signal Scan & Decoding: 6 real project signals (Synthetix-Grid, Jal Saathi, SyncPulse, Freshnest, StudyPulse, and OIBSIP) mapped in 3D space with category filtering and case-study modal drawers.

​Mission Log Timeline: Git-style deployment log showcasing achievements including the Smart India Hackathon (SIH) internal shortlist.

​Observatory CLI Terminal: Fully operational command-line interface supporting commands such as help, scan, sih, projects, skills, contact, and clear.

​Establish Contact Transmission Form: Interactive contact card equipped with direct email access and GitHub integration.

​Tech Stack
​Frontend Framework: HTML5, JavaScript (ES6+), Tailwind CSS
​3D Graphics & Rendering: Three.js (r128 WebGL Renderer)
​Icons & UI Assets: Lucide Icons
​Deployment Target: AWS Amplify Static Hosting via GitHub CI/CD
